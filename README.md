# Astro Bot

Асинхронный Telegram-бот для астрономов-любителей, разработанный на Python. Бот помогает рассчитывать точные интервалы видимости планет и объектов глубокого космоса (Каталог Мессье) для конкретной геопозиции наблюдателя с учетом технических характеристик его оптического оборудования.

---

## 🛠 Технологический стек

*   **Язык:** Python 3.11+
*   **Фреймворк бота:** `aiogram 3.x` (Асинхронный подход, использование FSM для пошаговых сценариев).
*   **Астрономические вычисления:** `Skyfield` (Использование точных эфемерид `de421.bsp`, расчет восходов/заходов и динамической яркости).
*   **База данных и ORM:** `SQLAlchemy 2.0` (Современный синтаксис `Mapped`), `aiosqlite` (Асинхронный движок для SQLite).
*   **Валидация данных:** `Pydantic v2` (Использование `TypeAdapter` для кэширования каталога объектов Мессье в ОЗУ, `@model_validator`).
*   **Утилиты:** `timezonefinder` & `zoneinfo` (Автоматическое определение локального часового пояса наблюдателя по гео-координатам), `APScheduler` (Фоновое планирование утренней рассылки).

## 📐 Математика и физика проекта

Бот производит прикладные оптические и астрономические расчеты на лету:

1. **Текущее увеличение ($Г$):** Зависит от фокусного расстояния трубы ($F$) и окуляра ($f$):
   $$Г = \frac{F}{f}$$
2. **Физические пределы трубы:** Максимальное полезное увеличение ($Г_{max} = 2 \cdot D$) и минимальное равнозрачковое увеличение ($Г_{min} = \frac{D}{6.5}$).
3. **Проницающая способность ($m_{lim}$):** Предельная звездная величина, которую способен уловить объектив диаметром $D$ мм:
   $$m_{lim} = 2.7 + 5 \cdot \log_{10}(D)$$
4. **Критерий видимости:** Бот сравнивает расчетную яркость объекта $V$ (динамическую для планет и статическую для Мессье) с возможностями прибора:
   $$V \le m_{lim}$$

## 🏗 Архитектура проекта

Проект разделен на независимые слои, что исключает связность кода:
*   `bot/` - Слой интерфейса Telegram. Содержит роутеры, хэндлеры и интерактивные inline-клавиатуры для управления сменной оптикой.
*   `db/` - Слой данных. Реализована реляционная схема **Пользователь (1) ➔ (1) Телескоп (1) ➔ (N) Окуляры**. Доступ к данным инкапсулирован в асинхронные CRUD-функции с использованием `selectinload` для оптимизации запросов (решение проблемы N+1). Управление сессиями построено на асинхронном контекстном менеджере с `yield`.
*   `services/` - Чистая бизнес-логика. Расчет астрономических окон (адаптирован под локальный полдень пользователя), кэширование JSON-каталога в память при старте и планировщик рассылки.

## 🔄 Реализованные сценарии 

1.  **Сценарий 1: Регистрация профиля (`/set_profile`)** - Пошаговый FSM-опрос параметров трубы, первого окуляра и отправки геопозиции с автоопределением UTC-смещения.
2.  **Сценарий 2: Чемоданчик оптики (`/add_eyepiece`)** - Добавление неограниченного числа окуляров в базу данных со связью 1:N.
3.  **Сценарий 3: Смена активной линзы (`/my_gear`)** - Интерактивный пульт управления, позволяющий «надеть» окуляр на телескоп в один клик через callback-запросы.
4.  **Сценарий 4: Автоматический прогноз** - Ежедневная фоновая рассылка в 8:00 по МСК, анализирующая небо под координаты каждого пользователя базы данных.

## 🚀 Запуск проекта

1. Клонируйте репозиторий и перейдите в папку:
   ```bash
   git clone <url_твоего_репозитория>
   cd astro-telescope-bot
   ```
2. Разверните виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Linux/macOS
   # или для Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Настройте конфигурационный файл (токен бота) и запустите приложение:
   ```bash
   python run.py
   ```
